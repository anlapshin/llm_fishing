# fishing

Скилл для OpenCode: консультант по спиннинговой ловле в Москве, Московской области и соседних регионах. Подбирает приманки и снасти под условия, объясняет проводку и выбор точки, разбирает неудачные выезды.

Настроен под конкретный арсенал и опыт владельца: Центральная Россия, открытая вода, хищник и белая рыба на мормышинг.

## Что умеет

- Подобрать приманку по условиям: течение, температура воды, прозрачность, свет, ветер, тренд давления.
- Объяснить горизонт и темп проводки — два решения, из которых следует всё остальное.
- Предложить точку по эвристикам: бровка, обратка, устье притока, мост, граница травы.
- Спланировать выезд: когда ехать, что взять, чего ждать.
- Разобрать прошлую рыбалку и записать вывод в журнал.
- Проверить прогноз и ограничения, если вопрос про конкретную дату.

## Как принимает решения

1. Классифицирует запрос: конкретный вопрос, расплывчатый («хочу на рыбалку»), разбор или просьба задать вопросы.
2. Собирает условия — не больше четырёх уточнений и только те, что меняют рекомендацию.
3. Определяет горизонт и темп.
4. Подбирает класс приманки по свойствам, а не по бренду.
5. Выбирает точку и время.
6. Проверяет изменчивое: прогноз, воду, правила.
7. Отвечает карточкой.

Формат ответа по умолчанию:

```
🎣 Рыба · Водоём · Сезон

Где и почему
Горизонт / темп
Приманка: тип, размер, вес, заглубление, плавучесть, игра, цвет
Проводка
Точка
План Б
Уверенность
Ограничение
```

## Установка

Скилл читается из `~/.agents/skills`. Склонируйте репозиторий туда:

```bash
git clone <repo-url> ~/.agents/skills/fishing
```

Или оставьте проект в удобном месте и создайте ссылку:

```bash
ln -s /path/to/fishing ~/.agents/skills/fishing
```

После этого скилл доступен в сессиях OpenCode по имени `fishing`.

## Примеры запросов

- «Судак с берега на Москве-реке в ноябре, вода +4. Что взять?»
- «Щука на Волге у Старицы, июль, жара, трава. Чем ловить?»
- «Голавль на малой реке, май, мутная вода после дождя.»
- «Где ловить завтра в пределах 50 км от Москвы?»
- «Разбери, почему не клевало в прошлую субботу.»

## Принципы

- Приманка описывается свойствами: тип, длина, вес, заглубление, плавучесть, игра, цвет по условию. Бренд — только как ориентир или по запросу.
- Один основной вариант и две альтернативы вместо списка из десяти.
- У каждой рекомендации есть план Б и уровень уверенности.
- Локальные факты не выдумываются: глубины, координаты и «секретные точки» — только как гипотеза.
- Прогноз и правила проверяются инструментом. Нет проверки — нет цифры.
- Запрет упоминается одной строкой после техники, без отказа от ответа и без предложений обойти правило.

## Данные и приватность

`data/inventory.md` и `data/journal.md` содержат личные вещи: снасти, приманки, места ловли, результаты. Перед публикацией репозитория решите, готовы ли вы их показывать; при необходимости очистите файлы или держите репозиторий приватным.

## Ограничения

- Регион — Центральная Россия; для других регионов справочники придётся дополнять.
- Таблица запретов и норм в `references/regulations.md` не заполнена проверенными данными: скилл отправляет к официальным источникам и просит проверить перед выездом.
- Прогноз берётся из Open-Meteo на 1–3 дня; дальше — сценарии.
- Вибы и колебалки в рекомендациях не используются: владелец их не применяет.
- Джиг, резина, мормышки и вертушки не учитываются поштучно — рекомендуются по весу, размеру, номеру и цвету.
- Ледовая ловля вне профиля.

## Статус

Рабочая версия. Проверена в чистых контекстах на вопросах про судака, щуку, голавля, мормышинг и планирование выезда.
