# Приманки: язык свойств

## Схема описания

Описывать приманку так, чтобы её можно было найти в своём ящике или подобрать в магазине без привязки к бренду.

| Поле | Значения |
|---|---|
| Тип | минноу, крэнк, стик, уокер, поппер, резина, поролон, пилькер, кастмастер, вертушка, мормышка |
| Длина | мм |
| Вес | г |
| Заглубление | м на равномерке; для тонущих — скорость погружения |
| Плавучесть | плавающая, суспендер, тонущая |
| Игра | роллинг, виляние, глайд, активная, пассивная, без игры |
| Акустика | шумная (погремушка), тихая |
| Цвет | по условию, не по названию расцветки |
| Горизонт | поверхность, 0,5–2 м, 2–5 м, дно |

## Соответствие условиям

| Ситуация | Тип | Размер | Плавучесть | Темп |
|---|---|---|---|---|
| Мелководье 0,5–1,5 м, тёплая вода | минноу, крэнк, стик | 50–90 мм | плавающая, суспендер | средний |
| Трава и окна | топвотер, стик без лопасти, незацепляемая резина | 60–100 мм | плавающая | средний, с паузами |
| Глубина 3–6 м, слабое течение | джиг, поролон, тонущий минноу | 60–90 мм / 2,5–4″ | тонущая | медленный, ступенька |
| Сильное течение | тяжёлый джиг, пилькер, тонущий минноу | по весу | тонущая | медленный, с удержанием |
| Холодная вода 2–8 °C | мелкий минноу, поролон, джиг | 50–80 мм | тонущая, суспендер | очень медленный, паузы 3–5 с |
| Мутная вода | резина с активной игрой, поролон, шумная приманка | +1 размер | тонущая | медленный, ближе |
| Ночь, сумерки | поверхностный минноу, крупный воблер | 90–130 мм | плавающая | медленный, с паузами |
| Голавль на течении | стик, крэнк SSR | 35–60 мм | плавающая, суспендер | средний, короткие твичи |
| Жерех | кастмастер, пилькер, топвотер | 10–25 г | тонущая / плавающая | быстрый |
| Окунь | микроджиг, мелкий воблер, вертушка | 40–70 мм / 1,5–3″ | любая | ступенька, твич |

## Размер

| Длина | Кого ловим |
|---|---|
| 35–50 мм | голавль, окунь, белая рыба, жерех |
| 50–70 мм | окунь, голавль, некрупная щука, жерех |
| 70–90 мм | судак, щука, крупный окунь |
| 90–130 мм | щука, крупный судак |
| 130 мм и больше | щука осенью и в период нагула |

Правило: на холодной и мутной воде размер не увеличивать, а уменьшать — исключение только для мутной воды, где +1 размер компенсирует видимость.

## Плавучесть

- **Плавающая:** мелководье, трава, быстрый поиск горизонта. Хорошо для новичка: видно, где идёт приманка.
- **Суспендер:** паузы. Главный класс для холодной воды и судака: на паузе приманка стоит в горизонте и провоцирует.
- **Тонущая:** глубина, течение, дальний заброс. Управляемая скорость погружения важнее общего веса.

## Цвет по условиям

| Условия | Цвет |
|---|---|
| Прозрачная вода, солнце | натуральные: окунёвый, плотвиный, серебро, оливковый |
| Прозрачная вода, пасмурно | натурал + контрастная спина, золото |
| Мутная вода | кислотный, чёрный, белый, золото, UV |
| Сумерки и ночь | тёмный силуэт, белый, чёрный с блеском |
| Яркое солнце, тень | тёмный силуэт, натурал |
| Сильное течение | контраст, крупный рисунок |

Цвет — последний параметр после горизонта, размера и темпа. Не менять цвет, пока не проверены горизонт и скорость.

## Игра и темп

- **Роллинг и активное виляние** — поиск активной рыбы, тёплая вода, широкий горизонт.
- **Глайд и стик** — паузы, точечная подача, осторожная рыба.
- **Пассивная игра, узкая амплитуда** — холодная вода, мутная вода, давление.
- **Шумная приманка** — мутная вода, ночь, сильное течение; в прозрачной воде и штиле может отпугивать.

## Подбор аналога

Когда пользователь просит «чем заменить» конкретную модель:

1. Определить класс и три свойства, которые нельзя терять: заглубление, плавучесть, вес (или размер).
2. Назвать 2–3 альтернативы в этом классе, объяснив, какое свойство сохранено, а какое отличается.
3. Не предлагать «любой похожий воблер» и не перечислять весь ассортимент магазина.

## Ошибки

- Путать длину и вес: 90 мм может весить и 8 г, и 20 г — это разные снасти.
- Менять цвет, не проверив горизонт.
- Ставить крупную приманку на холодную воду «чтобы отсечь мелочь» — обычно отсекается поклёвка.
- Заглубление «на глаз»: на течении реальная глубина хода меньше паспортной.
